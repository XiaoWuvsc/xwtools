## 📖 简介

**xwtools** 是一个由初中生 XiaoWu 开发的纯前端工具箱，所有工具均在浏览器本地运行，**不上传任何用户数据**。目前包含 10 个实用工具，涵盖 AI 调试、效率测试、魔方计时、编解码、密码生成、二维码、番茄钟、全球时间、计时器/秒表以及经典扫雷游戏。

## 🚀 快速开始

### 1. 直接下载使用

将本项目所有文件（`index.html` 及各个工具页面）下载到本地，双击 `index.html` 即可在浏览器中运行（推荐使用 Chrome / Edge / Firefox）。

> ⚠️ 注意：由于浏览器安全策略，DeepSeek API 测试需要您自行配置 API Key，并确保通过 HTTP 服务器访问（直接双击可能无法创建 Web Worker）。

### 2. 本地服务器运行（推荐）

使用任意静态服务器工具：

```bash
# Python 3
python -m http.server 8080

# Node.js (npx)
